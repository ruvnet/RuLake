# 02 — witness-verifier-nodejs (Rust → wasm32-unknown-unknown, --target nodejs)

Same Rust verifier as `01-witness-verifier-browser`, retargeted to Node.js
via `wasm-pack build --target nodejs`. The output is a CommonJS module
Node `require()`s directly.

## What it proves

A Node.js process can verify ruLake bundle integrity with no native
dependencies — only the wasm artifact and the wasm-bindgen JS glue
emitted by wasm-pack. Useful for build pipelines, CI verification of
bundle artifacts, and serverless functions that gate on bundle
identity.

## Build

```bash
./build.sh           # wasm-pack build --target nodejs --release
```

Outputs land in `pkg/`:

```
pkg/
├── package.json
├── rulake_witness_verifier_nodejs.js          # CJS glue
├── rulake_witness_verifier_nodejs_bg.wasm     # the wasm
└── rulake_witness_verifier_nodejs.d.ts
```

## Use

```bash
# CLI
node verify.js /tmp/rulake-sidecar-demo-12345/table.rulake.json

# tests
npm test     # uses node:test, no external framework
```

Sample CLI output:

```
PASS  /tmp/rulake-sidecar-demo-9999/table.rulake.json

  data_ref       : local://publisher/memories

  lineage_id     : —

```

## Programmatic use

```js
const { verify_bundle_json } = require("./pkg/rulake_witness_verifier_nodejs.js");
const fs = require("node:fs");

const text = fs.readFileSync("table.rulake.json", "utf8");
const r = verify_bundle_json(text);
if (!r.ok) throw new Error(`bundle ${r.computed} ≠ stored ${r.stored}`);
```

## Tests

`tests/verify.test.js` covers:

- known-good Rust-produced bundle verifies green
- `dim` tamper → red
- `data_ref` tamper → red
- `format_version > 2` → throws (no forward compat)
- 64 KiB DoS cap → throws
- collision regression: `Num(7)` vs `Opaque("\x07\0\0\0\0\0\0\0")` produce
  different witnesses (variant tag byte from 2026-04-23 audit)
- length-prefix regression: `Opaque("a|b")` vs `Opaque("ab|")` differ
- `memory_class` does NOT affect the witness

```bash
npm test
# ▶ verifies a real Rust-produced sidecar
# ▶ rejects a tampered bundle (dim flipped)
# ...
# ✔ all tests passed
```
